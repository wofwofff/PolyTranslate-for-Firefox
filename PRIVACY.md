# Privacy

When you choose to translate text, PolyTranslate opens Yandex Translate with that
text in the page URL. Yandex receives and processes the text as part of that
request. Text is not sent merely because you select it.

The extension does not include analytics or send data to a server operated by
the fork's maintainer. It uses Firefox sync storage for your extension settings.

The Firefox manifest declares `websiteContent` because translation sends selected
web page text to Yandex. Firefox presents this permission during installation.
